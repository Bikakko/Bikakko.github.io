# web-static

静态站点，纯前端、无运行时依赖。three.js 已内置在 `assets/vendor/`。

- `星空/` — 程序生成的星空背景页
- `太阳系/` — 严格等比例的太阳系轨道仪（J2000 轨道 / IAU 自转要素 / 实时历元）

## 本地预览

ES module + import map 需要 HTTP 服务，不能直接以 `file://` 打开：

```sh
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000/太阳系/solar.html`。

## 测试与打包

```sh
npm test     # node --test 太阳系/tests/*.test.mjs
npm run build  # 拷成可发布的 太阳系/dist（solar.html → index.html）
```

纯数学模块（`config.js` / `bodies.js` / `*-math.js` / `ephemeris-time.js`）
不依赖 DOM，可在 Node 里直接单测；渲染与相机交互层需要浏览器验证。

## 太阳系：查询参数

状态都可由查询参数复现，方便截图与分享。

| 参数 | 说明 |
| --- | --- |
| `?date=<YYYY-MM-DDTHH:MM:SS>` | 民用时间历元，按 `?zone=` 解释；不带秒也可以 |
| `?jd=<儒略日>` | 以 **TT** 儒略日指定历元（`2451545.0` = J2000.0） |
| `?t=<天>` | 距 J2000.0 **TT** 的天数，决定截图历元 |
| `?zone=<分钟 \| IANA 名>` | 时区：`480` = UTC+8，或 `Asia/Shanghai`；缺省用系统本地 |
| `?lat= / ?lon=` | 观测地纬度 / 经度（度，北纬东经为正），缺省北京 |
| `?static=1` | 冻结时间与着色器动画，保证同一历元每次出图一致 |
| `?focus=<天体名>` | 直接聚焦（含太阳、月球） |
| `?az= / ?el= / ?dist=` | 覆盖全景相机的方位 / 仰角 / 距离 |
| `?size=<倍数>` | 只放大天体半径用于对比（轨道不变） |
| `?debug=1` | 加载 `window.__dbg` 调试探针 |
| `?light=1` | 打开光速可视化 |
| `?rate=<倍率>` | **统一时间流速**（每真实秒推进多少模拟秒）：`1` / `60` / `600` / `3600` / `21600` / `86400` / `604800` / `2592000`；`?lrate=` 是兼容别名 |
| `?lt=<光秒>` | 打开光速模式时把统一时间定格在「发射后 lt 秒」，配合截图复现 |
| `?lstatic=1` | 打开光速模式时暂停统一时间 |

历元优先级：`?t=` > `?jd=` > `?date=` > **本机当前时间**。都不给时打开即
「实时跟随」，直接读系统时钟。

## 真实时间与输入时间

打开页面就是**此刻**的太阳系：`simTime` 每帧由 `Date.now()` 换算，不累加
帧间隔，所以挂着几小时也不会与手表错开（实测漂移 ≤ 2 ms）。点「现在」
随时回到实时跟随；选任何倍率或输入时间就退出跟随，改按统一时间轴走。

HUD 的「时间 ▸」打开时间面板：

- **日期时间**输入框（秒级）、**儒略日**输入框，两者双向同步；
- **时区**：系统本地 / 跟随观测地 / 固定 UTC 偏移。观测地选真实城市时走
  IANA 时区数据库，历史夏令时自动正确（悉尼 3 月是 AEDT+11、
  朗伊尔城 6 月是 CEST+2）；
- **步进**：年 / 月 / 日按民用日历走（跨夏令时保持本地钟点，1 月 31 日
  加一月落在 2 月 28 日），时 / 分 / 秒按绝对时长走；
- **复制状态链接**：把当前历元 + 时区 + 观测地写成可复现的 URL。

右上角状态卡给出当前历元、当前观测地的实时读数：季节与下一个节气、
太阳直射点经纬度、昼夜与太阳高度方位、日出日落与昼长（含极昼极夜）、
真太阳时与时差、月相与照亮比例，展开还能看八颗行星的日心黄经与距离。
观测地可换城市，也可以直接填经纬度。

## 光速可视化

`L` 键或左下角的「光速」开关打开 / 关闭（面板内的暂停、关闭按钮已移除，
开关常驻）。**全站只有一个时间轴** `simTime`
（距 J2000 的天数）和一套倍率（模拟秒 / 真实秒）：行星公转 / 自转与光波前
都由它派生，不再有第二个时钟，也不会出现「光速一个速度、天体又一个速度」。

- `lightSec = (simTime − emissionT) × 86400`，波前半径 `= c·lightSec / KM_PER_UNIT`。
  暂停、重播、拖动标尺、切换倍率都作用于同一个 `simTime`，光与天体永远同步；
  HUD 的「播放速度」是唯一的速度显示。
- **c 恒为 299792.458 km/s**。光行时按太阳中心 → 天体的瞬时距离计算，
  偏心率浮动可见（J2000 时水星 3m53s、地球 8m11s、海王星 4h10m29s）。
- **3D 光球**：波前是单个真实 3D 半透明球面，随镜头正确透视——
  - 球面着色器画经纬网格 + fresnel 轮廓光，`DoubleSide` 让相机在球内也能
    看到内表面；所有线都是统一普通亮度，没有又亮又粗的高亮大圆（主分支
    的三个正交大圆已取消）；
  - 普通子午线加密到 **32 条**（着色器 `lon * 16`），赤道/黄道线由
    `lat = 0` 的网格线给出；线宽按屏幕导数归一化，光球很小也看得见；
  - 八条太阳 → 行星光线，按波前半径裁断，前端 6% 高亮；每条光线上按
    **整数光秒**间隔布置明亮的圆点亮点（`THREE.Points` 点精灵，`gl_PointCoord`
    画亮核 + 光晕、恒定屏幕大小），相当于「k 秒前发出的光子」，随波前以
    光速向外流动。真实比例下 1 光秒在全景视距只投影成 0.035px，因此步长
    按视距自适应：始终保证相邻点屏幕间距 ≥ 12px，八条光线共用同一步长，
    面板实时显示当前的「每段 N 光秒」。点径不超过间距的 3/4，任何缩放下
    都不会重叠糊成亮线；拉近到行星附近步长回到 1，一颗颗 1 光秒的光点
    清晰可数，直观体现光速。
  相机被光球包裹时球面网格依然可见，面板标注「光球已包裹观察点」。
- **对数光时标尺**：`1 光分 → 4 光时` 刻度上钉着八颗行星，波前越过时点亮；
  标尺同时是 scrubber，拖动即把统一时间定位到任意光行时（只定位，
  不改变播放状态，不再自动暂停）。
- 倍率档 `1:1 / 1m / 10m / 1h / 6h / 1d / 7d / 30d`（每真实秒推进量）。
  `1:1` 是真实时间（光到海王星要等 4 小时 10 分），也是打开光速模式时的
  默认档；`?rate=` 可指定其它倍率。空格暂停 / `R` 重播 / `P` 播放。

未实现（方案中标为 P2 的扩展）：同时性/迟滞视图的幽灵天体、光子与探测器竞速。

## 太阳系：操作

左键拖动环绕、右键拖动平移、WASD 移动/环绕、滚轮或双指推拉、点击天体或标签
聚焦、Esc 或点空白取消聚焦、双击空白或「全景」回到远景、空格暂停、`L` 光速。

HUD 上的 `现在` 回到实时跟随，`❚❚ / 1:1 / 1m / … / 30d` 是**每秒推进多少
模拟时间**，不是真实速度的倍数；`时间 ▸` 打开时间面板。鼠标悬停按钮可看
完整说明。左上角的时间面板与左下角的光速面板共用左侧空间，同时只开一个。

## 数据与精度边界

- **时间尺度**：内部 `simTime` 是距 **J2000.0 TT**（JD 2451545.0 TT）的天数，
  不是 UTC。民用时间经 ΔT = 32.184 s + (TAI−UTC) 换算，闰秒表内置到
  2017-01-01（2026 年 ΔT = 69.184 s）。忽略 DUT1（≤ 0.9 s），
  所以民用钟表读数与世界时相差不到 1 秒。
- **轨道**：JPL SSD *Approximate Positions of the Planets* **Table 1** 的
  J2000 要素 + 每世纪线性速率，有效区间 **1800–2050 AD**。未包含 Table 2b
  的 `b/c/s/f` 附加项（木星—海王星长周期摄动），跨千年级别历元精度有限。
  超出区间时面板会标注「位置仅供参考」，仍然计算。
- **轨道线**：按当前历元采样，离散跳转（输入时间、步进、现在）时重采，
  连续拖动光速标尺不重采。地球的轨道线额外含地月质心摆动。
- **自转 / 极轴**：IAU WGCCRE 2015 / NAIF `pck00011.tpc`，交点系按
  RA = α₀+90°、Dec = 0 定义（地球极轴与参考极重合，不能用 k×p）；
  月球为 2009 IAU 值，未建模天平动与太阳摄动引起的高频项。
- **昼夜**：太阳视黄经含 IAU2006 岁差、四项章动与光行差；日出日落取
  地平高度 −0.833°（大气折射 + 日面半径），按当前观测地纬度解算。
- **比例**：天体半径与轨道距离共用 `KM_PER_UNIT`，默认不做任何放大。
  「最小可见光点」是屏幕空间 UI 层，不参与比例计算。
- **卫星数**：2026-11 的 JPL 快照，会随时间变化。

## 渲染注意事项

真实比例下地球半径只有约 `0.0004` 世界单位，因此近平面最小可到 `1e-6`、
远平面 `6000`（比值约 `6e9`），已启用 `logarithmicDepthBuffer`。
**所有自定义 `ShaderMaterial` 都必须注入 `shaders.js` 的 `LOGDEPTH_*`
片段**，否则与内建材质的深度编码不一致，远景会被裁掉。

自定义着色器刻意绕过 ACES / sRGB 色彩管线（直接输出原始颜色），
改动取色需要整体重新调色。
