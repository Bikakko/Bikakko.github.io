# web-static

静态站点，纯前端、无构建步骤。three.js 已内置在 `assets/vendor/`。

- `星空/` — 程序生成的星空背景页
- `太阳系/` — 严格等比例的太阳系轨道仪（J2000 轨道 / IAU 自转要素）

## 本地预览

ES module + import map 需要 HTTP 服务，不能直接以 `file://` 打开：

```sh
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000/太阳系/solar.html`。

## 测试

```sh
npm test
# 等价于 node --test 太阳系/tests/*.test.mjs
```

纯数学模块（`config.js` / `bodies.js` / `*-math.js`）不依赖 DOM 或 three.js，
可在 Node 里直接单测；渲染与相机交互层需要浏览器验证。

## 太阳系：查询参数

状态都可由查询参数复现，方便截图与分享。

| 参数 | 说明 |
| --- | --- |
| `?t=<天>` | 距 J2000 的天数，决定截图历元 |
| `?static=1` | 冻结时间与着色器动画，保证同一 `?t=` 每次出图一致 |
| `?focus=<天体名>` | 直接聚焦（含太阳、月球） |
| `?az= / ?el= / ?dist=` | 覆盖全景相机的方位 / 仰角 / 距离 |
| `?size=<倍数>` | 只放大天体半径用于对比；HUD 会如实标注「不再等比例」 |
| `?debug=1` | 加载 `window.__dbg` 调试探针 |
| `?light=1` | 打开光速可视化（见下） |

## 太阳系：操作

左键拖动环绕、右键拖动平移、WASD 移动/环绕、滚轮或双指推拉、点击天体或标签
聚焦、Esc 或点空白取消聚焦、双击空白或「全景」回到远景、空格暂停。

HUD 上的 `真实 / 30m / 3h / … / 30d` 是**每秒推进多少模拟时间**，不是真实
速度的倍数；鼠标悬停按钮可看完整说明。

## 数据与精度边界

- **轨道**：JPL SSD *Approximate Positions of the Planets* **Table 1** 的
  J2000 要素 + 每世纪线性速率，有效区间 **1800–2050 AD**。未包含 Table 2b
  的 `b/c/s/f` 附加项（木星—海王星长周期摄动），跨千年级别历元精度有限。
- **轨道线**：静态参考轨迹，按 `?t=` 所在历元采样一次；长期项造成的轨道面 /
  近日点缓慢进动不会逐帧重建。地球的轨道线额外含地月质心摆动。
- **自转 / 极轴**：IAU WGCCRE 2015 / NAIF `pck00011.tpc`；月球为 2009 IAU
  值，未建模天平动与太阳摄动引起的高频项。
- **比例**：天体半径与轨道距离共用 `KM_PER_UNIT`，默认不做任何放大。
  「最小可见光点」是屏幕空间 UI 层，不参与比例计算。
- **卫星数**：2026-11 的 JPL 快照，会随时间变化。

## 渲染注意事项

真实比例下地球半径只有约 `0.0004` 世界单位，因此近平面最小可到 `1e-6`、
远平面 `6000`（比值约 `6e9`），已启用 `logarithmicDepthBuffer`。
**所有自定义 `ShaderMaterial` 都必须注入 `shaders.js` 的 `LOGDEPTH_*`
片段**，否则与内建材质的深度编码不一致，远景会被裁掉。

自定义着色器刻意绕过 ACES / sRGB 色彩管线（直接输出原始颜色），
改动取色需要整体重新调色。
