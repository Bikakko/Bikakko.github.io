# web-static

静态站点，纯前端、无构建步骤。three.js 已内置在 `assets/vendor/`。

- `星空/` — 程序生成的星空背景页
- `太阳系/` — 严格等比例的太阳系轨道仪（J2000 轨道 / IAU 自转要素）

## 本地预览

ES module + import map 需要 HTTP 服务，不能直接以 `file://` 打开：

```sh
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000/太阳系/solar.html`。

## 测试

```sh
npm test
# 等价于 node --test 太阳系/tests/*.test.mjs
```

纯数学模块（`config.js` / `bodies.js` / `*-math.js`）不依赖 DOM 或 three.js，
可在 Node 里直接单测；渲染与相机交互层需要浏览器验证。

## 太阳系：查询参数

状态都可由查询参数复现，方便截图与分享。

| 参数 | 说明 |
| --- | --- |
| `?t=<天>` | 距 J2000 的天数，决定截图历元 |
| `?static=1` | 冻结时间与着色器动画，保证同一 `?t=` 每次出图一致 |
| `?focus=<天体名>` | 直接聚焦（含太阳、月球） |
| `?az= / ?el= / ?dist=` | 覆盖全景相机的方位 / 仰角 / 距离 |
| `?size=<倍数>` | 只放大天体半径用于对比；HUD 会如实标注「不再等比例」 |
| `?debug=1` | 加载 `window.__dbg` 调试探针 |
| `?light=1` | 打开光速可视化 |
| `?rate=<倍率>` | **统一时间流速**（每真实秒推进多少模拟秒）：`1` / `60` / `600` / `3600` / `21600` / `86400` / `604800` / `2592000`；`?lrate=` 是兼容别名 |
| `?lt=<光秒>` | 打开光速模式时把统一时间定格在「发射后 lt 秒」，配合截图复现 |
| `?lstatic=1` | 打开光速模式时暂停统一时间 |

## 光速可视化

`L` 键或 HUD 上的「光速」按钮打开。**全站只有一个时间轴** `simTime`
（距 J2000 的天数）和一套倍率（模拟秒 / 真实秒）：行星公转 / 自转与光波前
都由它派生，不再有第二个时钟，也不会出现「光速一个速度、天体又一个速度」。

- `lightSec = (simTime − emissionT) × 86400`，波前半径 `= c·lightSec / KM_PER_UNIT`。
  暂停、重播、拖动标尺、切换倍率都作用于同一个 `simTime`，光与天体永远同步；
  HUD 的「时间流速」是唯一的速度显示。
- **c 恒为 299792.458 km/s**。光行时按太阳中心 → 天体的瞬时距离计算，
  偏心率浮动可见（J2000 时水星 3m53s、地球 8m11s、海王星 4h10m29s）。
- **3D 脉冲光球**：每层光球是真实 3D 半透明球面，随镜头正确透视——
  - 球面用普通混合（非加性）、不透明度极低：fresnel 轮廓可见、球心方向
    基数压到 0.04，所以 N 层同心球壳也不会「越靠近中心越亮」；
  - 经纬线（10 纬 / 16 经，1px 线宽，统一普通亮度）、黄道大圆与两条
    子午圆都只画在**主波前球**上，整套场景只有这一套，避免叠成密密麻麻
    的平行线；
  - 每个光球有**固定的发射光行时** `emit_k = k·5 光秒`（物理量，与倍率
    无关），当前半径 `R_k = c·(t − emit_k)`。三条不变量由数学保证：
    `dR/dt ≡ c`（严格光速，不可能超光速）、`k` 覆盖全部已发射球壳所以
    波纹**铺满 0..主波前全程**（不会再挤在中心一小块）、相邻球壳间距恒为
    5 光秒的距离。历史上「超光速 / 太小 / 心跳」都来自每帧按当前 `t` 的
    归一化比例重算球壳位置，现在发射时刻是常数，这三种故障都不再可能。
  - 屏幕上无法清晰显示物理上的 3001 层：`pulseStride` 按**相机像素尺度**
    选一个 2 的幂抽样步长 `stride`，只画落在 5 光秒整数网格上的球壳。
    `stride` 只依赖相机、不依赖 `t`，所以播放中球壳索引集合恒定、平滑
    推进；可见窗口两端的增删由淡入淡出隐藏。全景下 `stride` 让波纹铺满
    全系且稀疏清晰，**拉近到太阳附近 `stride → 1`，能看到逐 5 光秒的
    细波纹**。纯函数 `pulseRadii`，暂停 / 重播 / 拖标尺 / `?lt` 截图一致。
  - **两种观感按相机位置切换**（`sweepWeight` 纯函数与 GLSL 同式）：
    - **光球外**（相机在主波前之外）：所有球壳正常画成完整 3D 球面，
      看到一个个向外扩张的光球；
    - **光球内**（相机被主波前包裹）：球面退成极淡底衬，改画每个波面与
      「面向相机的观察平面」的交圆 —— 一圈圈同心正圆，亮度按波面是否正
      掠过视野调制，随时间从中心一圈圈向外扩张、一道道扫过视野，即
      「一波一波的光波扫过去」。用面向相机的圆而非黄道大圆，避免透视下
      远半压缩成密集平行弧线；线用普通混合，不叠加成亮团。
    - 主波前球（带经纬网）始终保留作方位参考。
  - 八条太阳 → 行星光线，按主波前半径裁断，前端 6% 高亮；光线上每隔
    **1 光秒**有一个亮点，亮点随波前以光速向外流动。
  `?pulse=<光秒>` 可改脉冲的物理间隔。
- **对数光时标尺**：`1 光分 → 4 光时` 刻度上钉着八颗行星，波前越过时点亮；
  标尺同时是 scrubber，拖动即把统一时间定格到任意光行时。
- 倍率档 `1:1 / 1m / 10m / 1h / 6h / 1d / 7d / 30d`（每真实秒推进量）。
  `1:1` 是真实时间（光到海王星要等 4 小时 10 分），也是打开光速模式时的
  默认档；`?rate=` 可指定其它倍率。空格暂停 / `R` 重播 / `P` 播放。

未实现（方案中标为 P2 的扩展）：同时性/迟滞视图的幽灵天体、光子与探测器竞速。

## 太阳系：操作

左键拖动环绕、右键拖动平移、WASD 移动/环绕、滚轮或双指推拉、点击天体或标签
聚焦、Esc 或点空白取消聚焦、双击空白或「全景」回到远景、空格暂停。

HUD 上的 `真实 / 30m / 3h / … / 30d` 是**每秒推进多少模拟时间**，不是真实
速度的倍数；鼠标悬停按钮可看完整说明。

## 数据与精度边界

- **轨道**：JPL SSD *Approximate Positions of the Planets* **Table 1** 的
  J2000 要素 + 每世纪线性速率，有效区间 **1800–2050 AD**。未包含 Table 2b
  的 `b/c/s/f` 附加项（木星—海王星长周期摄动），跨千年级别历元精度有限。
- **轨道线**：静态参考轨迹，按 `?t=` 所在历元采样一次；长期项造成的轨道面 /
  近日点缓慢进动不会逐帧重建。地球的轨道线额外含地月质心摆动。
- **自转 / 极轴**：IAU WGCCRE 2015 / NAIF `pck00011.tpc`；月球为 2009 IAU
  值，未建模天平动与太阳摄动引起的高频项。
- **比例**：天体半径与轨道距离共用 `KM_PER_UNIT`，默认不做任何放大。
  「最小可见光点」是屏幕空间 UI 层，不参与比例计算。
- **卫星数**：2026-11 的 JPL 快照，会随时间变化。

## 渲染注意事项

真实比例下地球半径只有约 `0.0004` 世界单位，因此近平面最小可到 `1e-6`、
远平面 `6000`（比值约 `6e9`），已启用 `logarithmicDepthBuffer`。
**所有自定义 `ShaderMaterial` 都必须注入 `shaders.js` 的 `LOGDEPTH_*`
片段**，否则与内建材质的深度编码不一致，远景会被裁掉。

自定义着色器刻意绕过 ACES / sRGB 色彩管线（直接输出原始颜色），
改动取色需要整体重新调色。
